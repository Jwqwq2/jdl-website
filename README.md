# 京东物流官网复刻 · Vibe Coding 网页制作作业

## 运行

直接双击 `index.html` 即可使用，不需要安装依赖。图片、样式和脚本均在项目内，页面主体可离线访问。也可以使用任意静态网站服务器预览。

## 已实现

- 参照京东物流官网的顶部导航、供应链横幅、便捷查询入口、服务产品、行业解决方案、物流网络、新闻、页脚布局。
- 10 类物流服务切换、6 类行业方案切换，支持键盘左右方向键。
- 快递轨迹演示、寄件信息校验、运费与时效估算、服务范围与网点查询演示。
- 新闻详情弹窗、咨询入口、意见反馈演示、碳足迹计算演示、返回顶部。
- 桌面与手机响应式布局，原生弹窗支持 Esc 关闭，表单具备标签与输入校验。
- 表单仅在本机内存中运行，不发送、不保存个人信息。

## GitHub Pages 发布（免费）

1. 登录 GitHub，点击右上角 `+` → `New repository`，仓库名填写 `jdl-website`，选择 `Public`，创建仓库。
2. 点击 `uploading an existing file`（或 `Add file` → `Upload files`）。
3. 把本文件夹中的 **index.html、style.css、app.js、assets 文件夹** 拖入上传区。不要把外层“京东物流官网复刻”文件夹整体套进去；index.html 必须在仓库根目录。点击 `Commit changes`。
4. 打开仓库 `Settings` → `Pages`，在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，文件夹选择 `/(root)`，点击 `Save`。
6. 等待 GitHub Pages 完成构建，刷新 Pages 设置，复制顶部显示的网站链接。链接通常是 `https://你的GitHub用户名.github.io/jdl-website/`，请实际打开确认后提交。

不需要上传 output 文件夹。GitHub Pages 发布的是静态网站，不支持真实物流后台，本作品所有演示交互均可正常运行。
